Informativa sulla privacy

Ultimo aggiornamento: 22 settembre 2026

SPVault è un programma desktop che gira sul tuo PC: non ha un proprio server, non raccoglie dati per venderli o profilarti, e non manda nessuna telemetria. Questa pagina spiega con esattezza cosa succede — e cosa no — in termini semplici.

Il programma desktop

SPVault gira interamente sul tuo dispositivo. Parla solo con le pagine di accesso di Microsoft (nel browser, alla prima connessione) e con le API di SharePoint del tuo account — niente altro.

  • Nessun server proprio, nessuna telemetria. SPVault non manda a nessun server di sua proprietà informazioni di alcun tipo — non analytics, non crash report, non statistiche d’uso.
  • L’accesso avviene con il tuo browser. SPVault apre Chrome o Edge (già installati sul tuo PC) con un profilo dedicato e separato da quello che usi tutti i giorni, in %LOCALAPPDATA%\SPVault\browser_profile. Le credenziali le inserisci tu, direttamente nella pagina di accesso Microsoft — SPVault non le vede né le maneggia mai.
  • La sessione di accesso resta solo sul tuo PC. Dopo il primo accesso, SPVault riusa i cookie di sessione salvati in quel profilo dedicato per parlare con le API di SharePoint — non vengono mai inviati altrove.
  • I dati del backup restano dove li metti tu. I file copiati vanno nella cartella di backup che scegli, sul tuo disco o dentro il tuo OneDrive — mai su un server di SPVault, perché non esiste.
  • SPVault vede solo quello che vedi tu. Usa il tuo account e i tuoi permessi, nessun privilegio aggiuntivo: non può leggere né copiare niente che il tuo account non veda già nel browser.
  • Disinstallando SPVault restano i file che ha già copiato (sono tuoi, sul tuo disco) — i dati dell’app (sessione, impostazioni, stato) restano in %LOCALAPPDATA%\SPVault finché non li cancelli a mano.

Questo sito (la pagina che stai leggendo)

È un sito statico, senza form, senza account e senza analytics di alcun tipo. Due cose vengono comunque caricate da fuori il tuo browser, entrambe standard e dichiarate onestamente:

  • L’API pubblica delle release di GitHub — per mostrare se esiste già una versione scaricabile e il link giusto. La richiesta va dal tuo browser direttamente a GitHub; questo sito non la vede.
  • Google Fonts — i caratteri della pagina sono caricati dai server di Google, come sulla maggior parte dei siti che usano Google Fonts. Il tuo browser richiede quei file direttamente a Google.

Nessuna delle due è qualcosa che questo sito raccoglie o a cui ha accesso — sono richieste che il tuo browser fa direttamente a terzi, normali per una pagina che mostra l’ultima release e usa web font.

Modifiche a questa pagina
